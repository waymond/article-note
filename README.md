# 📰 기사 프로젝트 노트

기사 프로젝트를 정리하는 단일 HTML 노트 페이지입니다.
설치나 빌드 없이 `index.html` 파일 하나로 동작하며, 휴대폰에서도 잘 보이도록 만들었습니다.

## 구성

| 칸 | 설명 |
| --- | --- |
| 프로젝트 한 줄 | 프로젝트를 한 줄로 적는 칸 |
| 역할 | 내 역할을 적는 칸 |
| 주제 | AI와 산업과 직업 |
| 할 일 체크리스트 | 체크할 수 있는 할 일 5개 |
| 날짜별 기록 | 11/18부터 하루 한 줄씩 기록, 버튼으로 다음 날짜 추가 |

## 특징

- 노션·메모처럼 깔끔하고 읽기 편한 디자인
- 반응형 레이아웃 (휴대폰 · PC)
- 다크 모드 자동 지원
- 서버 없이 동작, 입력 내용은 브라우저에 자동 저장
- 전화번호·주소 같은 개인정보 입력칸 없음

## 사용 방법

1. 저장소를 내려받습니다.
2. `index.html`을 브라우저에서 엽니다.
3. 각 칸을 눌러 바로 입력합니다.

## GitHub Pages로 배포하기

1. 이 저장소에 `index.html`을 올립니다.
2. 저장소의 **Settings → Pages**로 이동합니다.
3. **Source**에서 배포할 브랜치와 폴더(`/ (root)`)를 선택하고 저장합니다.
4. 잠시 후 안내되는 주소로 접속합니다.

## 저장 방식

입력한 내용은 브라우저의 `localStorage`에 저장됩니다.

- 같은 기기, 같은 브라우저, 같은 주소에서만 다시 보입니다.
- 기기가 다르거나 주소가 바뀌면 이전 내용이 보이지 않습니다.
- 브라우저의 사이트 데이터를 지우면 저장된 내용도 사라집니다.
